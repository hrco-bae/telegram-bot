# 🎖️ 군대 관련 뉴스 텔레그램 봇

매일 아침 자동으로 군대 관련 최신 뉴스를 텔레그램으로 받을 수 있는 봇입니다.

## 🚀 시작하기

### 1. 봇 토큰 발급받기
1. 텔레그램에서 [@BotFather](https://t.me/BotFather)를 찾으세요
2. `/newbot` 명령으로 새 봇을 생성하세요
3. 봇 토큰을 받으세요 (형식: `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`)

### 2. 환경 설정
`.env.example` 파일을 복사해서 `.env` 파일을 만들고 토큰을 붙여넣으세요:
```bash
cp .env.example .env
```

그 후 `.env` 파일을 열고 토큰을 설정하세요:
```
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
```

### 3. 패키지 설치
```bash
npm install
```

### 4. 봇 실행
```bash
npm start
```

## 📌 봇 명령어

| 명령어 | 설명 |
|--------|------|
| `/start` | 봇 시작 및 사용법 안내 |
| `/subscribe` | 매일 아침 8시 30분(서울시간)에 뉴스 자동 수신 |
| `/unsubscribe` | 뉴스 구독 취소 |
| `/news` | 지금 바로 최신 뉴스 보기 |

## ✨ 주요 기능

- 🔔 **자동 뉴스 전송** - 매일 아침 8시 30분에 자동으로 뉴스 전송
- 📰 **한글 필터링** - 한글 뉴스만 수집하여 전송
- 🔗 **중복 제거** - 이미 전송한 뉴스는 다시 보내지 않음
- 👥 **구독 관리** - 사용자별로 구독/구독 취소 기능

## 📋 필요한 것

- Node.js v14 이상
- npm 또는 yarn
- 텔레그램 계정
- 인터넷 연결

## 📁 파일 구조

```
telegram-bot/
├── bot.js              # 봇 메인 코드
├── package.json        # 프로젝트 설정
├── .env               # 환경 변수 (토큰) - 절대 커밋하지 마세요!
├── .env.example       # 환경 변수 예시 파일
├── .gitignore         # Git 무시 파일
├── news_config.json   # 구독자 목록 (자동 생성)
├── last_news.json     # 이전 뉴스 URL 저장 (자동 생성)
└── README.md          # 이 파일
```

## 🔒 보안 주의사항

**.env 파일은 절대 깃허브에 올리지 마세요!**
- `.gitignore`에 `.env`가 포함되어 있으므로 자동으로 무시됩니다.
- 본인의 BOT_TOKEN을 공개 저장소에 올리면 누구나 봇을 악용할 수 있습니다.
